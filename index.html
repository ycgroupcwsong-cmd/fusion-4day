WHO IS THIS CLASS FOR?

어렵게 느껴졌던 Fusion,
배우는 속도부터 달라집니다.

짧은 시간에 많은 기능을 배우고 나면, 막상 혼자 작업할 때 순서가 기억나지 않을 수 있습니다. 이 과정은 처음 보는 화면과 용어부터 반복해서 사용하는 기능까지 충분히 이해하는 데 초점을 맞춥니다.

01 / START

처음 시작해서
무엇부터 해야 할지 모를 때

화면 구성과 조작부터 익히고, 작은 스케치를 직접 완성하며 시작합니다.

02 / REVIEW

배운 적은 있지만
혼자 하면 막힐 때

자주 잊는 기능과 작업 순서를 다시 정리하고 직접 반복합니다.

03 / DETAIL

하루에 배운 내용을
조금 더 깊이 이해하고 싶을 때

각 단계를 나눠 설명하고, 원리와 실제 사용 상황을 연결합니다.

04 / APPLY

목공 설계에서
CAM까지 이어가고 싶을 때

모델링만 배우는 데서 멈추지 않고 가공 준비 과정까지 익힙니다.
